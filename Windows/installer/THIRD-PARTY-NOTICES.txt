USBip for Windows (external dependency, not bundled)
----------------------------------------------------
The touchpad and Radial controller require the USBip driver. It is not
included in this installer; install it separately from:

    https://github.com/vadimgrn/usbip-win2

USBip is distributed under the BSD 2-Clause license by its own authors.


Control panel

runtime is not bundled. The installer does not check for or install it; users
must install the required runtime separately.
